# Satokausi Growth Audit

**Live → https://eddieatadapty.github.io/satokausi-flow-rebuild/**

Five ideas to turn more Satokausi users into subscribers, each built into a clickable version of Satokausi's own onboarding. Prepared by Adapty.

| # | Idea | Potential outcome |
| :-- | :-- | :-- |
| 01 | Open on the species the ad sold | +10–20% CR to purchase |
| 02 | One real patch before the price | +10–20% CR to purchase |
| 03 | Name the species on the paywall | +15–20% CR to purchase |
| 04 | Show what the year buys in winter | +5–15% CR to purchase |
| 05 | Close into the season, not a second price | +3–8% CR to purchase |

Every price, rating and feature comes from Satokausi's App Store listing, website or in-app screens. Impact ranges are Adapty’s expected effect from teardowns and A/B tests across 30,000+ subscription apps, not measured lift for Satokausi. They overlap, so they don’t add up.

Static single page, no build step: `python3 -m http.server`.
